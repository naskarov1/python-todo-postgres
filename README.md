#  To-Do List CLI App

Консольное приложение (CLI) для управления списком задач с сохранением данных в PostgreSQL. Проект написан на Python с использованием SQLAlchemy ORM и современной подписи типов.

---

##  Технологический стек

* **Python 3.10+**
* **SQLAlchemy 2.0** — ORM для работы с базой данных (использован Declarative Mapping & Mapped Types)
* **psycopg 3** — современный асинхронно-синхронный драйвер PostgreSQL
* **python-dotenv** — безопасное управление переменными окружения
* **PostgreSQL** — реляционная база данных

---

##  Функциональность

-  **Добавление задач** с указанием названия, подробного описания и статуса.
-  **Просмотр списка задач** с удобным форматированием и отображением текущего статуса (`waiting`, `in progress`, `done`).
-  **Редактирование задач** (изменение названия, описания или статуса по выбору).
-  **Удаление задач** с подтверждением действия.
-  **Валидация ввода**: защита от пустых строк и превышения лимитов длины полей.
